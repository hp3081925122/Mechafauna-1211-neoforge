# 重型装甲战利品机枪：单管弹链方案

根据现实机枪的单管、长护套、弹链、独立枪托和两脚架轮廓重新设计。保留重型装甲的冷灰金属、克制青色和橙色卡扣配色。

## 参考与制作

- `reference.png`：内置 imagegen 生成的新版概念图，含整体、侧面、正面、背面及色板。
- `reference-prompt.md`：实际生成提示词和检索来源。
- `heavy_mech_machine_gun_beltfed.bbmodel`：可编辑完整工程，内嵌贴图。
- `heavy_mech_machine_gun_beltfed.json`：Java 物品模型，Blockbench 的 `1.9.0` 选项对应 Minecraft 1.9–1.21.5，适用于当前 1.21.1。
- `heavy_mech_machine_gun_beltfed.png`：原生 256×256 像素图集，按表面分别排 UV，左右对应面镜像复用。
- `parts/`：枪管护套、机匣、枪托握把、弹链弹箱、两脚架五部分的独立工程、导出、贴图与实际预览。
- `preview.png`：Blockbench 实际模型截图。

散热孔、铆钉和板面层次通过贴图表现；支架、握把、枪托、卡扣和弹链保留实体体积。模型共 60 个方块。弹箱与弹链在左侧，拉柄在右侧，为功能性非对称；其余主要结构保持对称。

## 检查记录与边界

`qa/validation.json` 记录导出数量、唯一标识、正体积、坐标范围、UV 边界、单轴旋转、二值透明度及工程内嵌贴图检查。`qa/turntable.webp` 保存 49 帧、360° 环绕及 −14° 至 30° 俯仰变化的实际 Blockbench 渲染；四张连续帧检查图和前后侧视图在同目录。

参考图与方块模型分别检查了单管轮廓、护套比例、供弹位置、枪托和材质主色。未把生成图当作模型截图。参考图中的圆滑倒角和工作室光照已按 Minecraft 方块与像素贴图方式简化。

目前只完成外观资源，尚未注册物品、接入掉落、射击、换弹或双手持枪动画。工程包含物品槽的初始显示变换，默认玩家垂臂姿态下枪托与前臂存在相交，后续需与实际持枪姿态一起调整。未启动游戏验证这些运行端表现。

本次没有修改 Java、现有六管机枪、实体模型或运行资源，因此没有以 Gradle 构建代替美术资源检查。
